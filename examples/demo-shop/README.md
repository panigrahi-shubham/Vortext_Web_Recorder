# Example: demo shop checkout

Generated by TPHub Web Recorder from one recording on the bundled demo shop
(`npx tsx scripts/make-example.ts`). Nothing here was edited by hand.

The flow: log in, add two products, open the cart, remove one row, fill the checkout form, tick the
terms checkbox, continue, place the order in the confirmation dialog.

Run it (two PowerShell windows, from the project root):

```powershell
npm run fixture-site
```

```powershell
$env:TEST_PASSWORD = 'secret_sauce'
npx playwright test -c examples/demo-shop
```

Things to look at:

- `tests/pages/InventoryPage.ts`: `addToCartButton(itemName)` scopes the button by the card text, so
  one method works for every product.
- `tests/pages/CartPage.ts`: the same for table rows (`getByRole('row').filter(...)`).
- `tests/specs/*.spec.ts`: one `test.step` per user intention, each with the suggested check that was
  ticked by default (URL, cart badge count, checkbox state, dialog, thank-you heading).
- `tests/fixtures/*.data.json`: the password is masked; the spec reads `TEST_PASSWORD`.
- `tests/recordings/*.recording.json`: regenerate in another style without recording again:
  `npx tsx src/cli.ts generate --from examples/demo-shop/tests/recordings/standard-user-buys-a-backpack.recording.json --style flat --out .tmp/flat`
